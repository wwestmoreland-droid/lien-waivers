# Templates

- `pdf/` — lien waiver PDF templates and their field-position YAML, keyed by state and waiver type
  (`pdf/default/` holds the three Buildout Pros templates). Added in Phase 2.
- `email/` — the fixed email templates from section 6A. Added in Phase 3.

Statutory state forms are supplied by counsel. The app never writes waiver form text itself.
